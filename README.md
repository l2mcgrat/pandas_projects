# pandas_projects
A set of data analytics scripts and programming tools made using pythons pandas library

## Physics: Dipole Atlas

[Simulation guide](phase_lab/README.md) · [Interactive demo](media/phase_simulations/demo_tp_20260925/index.html) · [PDF report](reports/phase_simulations/demo_tp_20260925/dipole_atlas.pdf)

[simulations.py](simulations.py) runs seeded OpenMM polar-molecule surrogates across
temperature/pressure paths, exports CSV records, and creates figures plus an
offline browser trajectory viewer. These are qualitative order/disorder experiments,
not calibrated melting, boiling or vapour-pressure predictions.

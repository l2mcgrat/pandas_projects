# pandas_projects
A set of data analytics scripts and programming tools made using pythons pandas library

## Connected portfolio & Mental Map

[Site preview](LiamMs_PandasProjects/index.html) · [Mental Map](LiamMs_PandasProjects/Mental-Map/index.html) · [Site atlas](LiamMs_PandasProjects/Atlas/index.html) · [Build and maintenance guide](site_content/README.md)

The home page is a hexagon of six fields around the Mental Map; each field opens
a hexagon of six topics, and each topic a hexagon of six destinations (6 → 36 →
216 pages, each with its own animated icon). A radial site atlas links all 259
nodes, and a snap-scrolling showcase of respected creators sits below the home
hexagon. Readers include a LaTeX Mental Map with linked contents and locally
rendered, numbered equations; vocabulary and feelings explorers from the music
archive; an algorithm index; and education/certifications. Source code and
editable styles live in [site_content](site_content/README.md), not in generated HTML.
The lightweight portfolio build preserves existing Smash data and physics runs.

## Physics: Dipole Atlas

[Simulation guide](phase_lab/README.md) · [Interactive demo](media/phase_simulations/demo_tp_20260925/index.html) · [PDF report](reports/phase_simulations/demo_tp_20260925/dipole_atlas.pdf)

[simulations.py](simulations.py) runs seeded OpenMM polar-molecule surrogates across
temperature/pressure paths, exports CSV records, and creates figures plus an
offline browser trajectory viewer. These are qualitative order/disorder experiments,
not calibrated melting, boiling or vapour-pressure predictions.
